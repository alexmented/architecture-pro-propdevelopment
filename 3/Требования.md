# Требования

- Все коммуникации между системами должны быть защищены по TLS
- API партнера должно изолировать данные между ЖК
- Соответствие требованиям ФЗ-152
- Добавление логирования операций
- Использование краткосрочного JWT токена для выполнение операций
- Прохождение аутентификации перед использованием сервиса
